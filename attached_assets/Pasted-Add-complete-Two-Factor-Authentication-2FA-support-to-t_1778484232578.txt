Add complete Two-Factor Authentication (2FA) support to the app.

Requirements:

1. Add `.env` configuration:

```env
ENABLE_2FA=true
```

Behavior:

* If `ENABLE_2FA=true`

  * 2FA system enabled
  * Setup flow enabled
  * Login verification enabled
  * Settings tab visible
* If `ENABLE_2FA=false`

  * Entire 2FA system disabled
  * No OTP verification
  * No setup screen
  * Hide 2FA tab
  * Existing DB values ignored

Backend restart required after `.env` changes.

---

First-Time Setup Flow:

After successful login:

Conditions:

* ENABLE_2FA=true
* user.twoFactorEnabled=false

Then immediately show a quick setup panel/modal:

# 2FA Setup

Options:

* Setup with QR Code
* Setup with Manual Key

Generate TOTP secret and QR.

QR format:

```text

```

Show:

* QR Code
* Manual secret key
* Copy button

Compatible with:

* Google Authenticator
* Authy
* Microsoft Authenticator
* 1Password

# Queue Based Build System

Do NOT allow unlimited parallel builds.

Add centralized queue-based build architecture.

Requirements:

* build queue
* worker system
* retry support
* build status tracking
* queued/building/success/failed states
* prevent server overload

Architecture:

```text id="f3"
Deploy Request
      ↓
Redis Queue / MQ
      ↓
Build Worker
      ↓
Docker Build OR RailPack Build
      ↓
Deploy
```

---

Add global reset method similar to SSH reset behavior.

Flow:

1. Change:

```env

```

2. Restart backend

Result:

* all users bypass 2FA
* users can login normally
* existing secrets ignored

If later:

```env
ENABLE_2FA=true
```

Then users without active setup must configure 2FA again.
